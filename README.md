# 运放仿真：放大器 / 音频放大

两个基于运算放大器的 Proteus 原理图仿真：

| 文件 | 内容 |
| --- | --- |
| `proteus/amplifier.pdsprj` | 基础运放放大电路（偏置、增益、反馈） |
| `proteus/audio-amp.pdsprj` | 音频放大电路（交流耦合、增益级、输出级） |

## 使用

1. 用 Proteus 8.13+ 打开对应 `.pdsprj`。
2. 用函数发生器输入正弦/音频信号，用示波器观察输入输出波形、增益、相位和失真。
3. 调整反馈电阻、偏置和耦合电容，观察带宽、增益和削顶行为。

## 说明

- 这是模拟电路仿真，不含单片机固件。
- 仿真用的是理想/通用运放模型，实际电路还需要考虑运放带宽、压摆率、输入失调、噪声、电源抑制和负载能力。
- 元件参数以原理图内标注为准。
